Canonical Data Contract

Long-Form Observation Model

Decouples multi-source indicator observations from rigid physical table columns. Every empirical measurement conforms to this 14-field specification.

Field Name Data Type Nullable Category Description Example
region_id String No (PK) Required Stable geographic code (Census 2011, LGD, or ISO code). 29_572
region_name String No Required Official human-readable region label in Title Case. Bengaluru Urban
parent_region_id String Yes Contextual Parent administrative territory identifier (e.g., state code). ST_KA
geographic_level String No Required Supported hierarchy: district, state, block, national. district
indicator_code String No (PK) Required Stable uppercase code for measured indicator. LIT_RATE_TOT
indicator_name String No Required Descriptive human-readable indicator name. Total Literacy Rate
value Float Yes (NaN) Required Numeric observation. Missing values remain NaN; never replaced with zero. 78.5
unit String No Required Measurement unit. Must be uniform across rows for a given indicator. percentage
reference_period String No (PK) Required Validated period string (e.g. YYYY, YYYY-YY, QX-YYYY). 2021-22
source_id String No Required Foreign key linking to Dataset Source Registry. SRC_CENSUS_2011
source_record_id String Yes Contextual Source row or table index line reference for lineage audit. REC_001
quality_status String Yes Contextual Validation state: raw, provisional, validated, synthetic. validated
